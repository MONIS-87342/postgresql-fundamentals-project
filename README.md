# PostgreSQL Fundamentals Project

## Project Overview
This project contains hands-on PostgreSQL practice queries using realistic datasets for employees, customers, departments, and orders tables.

The project was created to strengthen SQL and Data Analyst skills through practical query writing and database management tasks.

---

## Topics Covered

### SQL Fundamentals
- SELECT Statement
- WHERE Clause
- ORDER BY
- LIMIT / OFFSET

### Data Manipulation
- INSERT INTO
- UPDATE
- DELETE

### Table Operations
- CREATE TABLE
- ALTER TABLE
- DROP TABLE

### Constraints
- PRIMARY KEY
- FOREIGN KEY
- UNIQUE
- NOT NULL
- CHECK Constraint

### Filtering Operators
- AND / OR / NOT
- IN Operator
- BETWEEN Operator
- LIKE Operator
- IS NULL / IS NOT NULL

### Aggregate Functions
- COUNT
- SUM
- AVG
- MIN
- MAX

### Grouping & Analysis
- GROUP BY
- HAVING
- DISTINCT
